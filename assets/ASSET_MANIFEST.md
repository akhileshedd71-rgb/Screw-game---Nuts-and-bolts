# Screwcraft asset provenance

Game visuals and sounds are built for this project. The attached diagrams are
design references, not a texture sheet copied into the game. No competitor art,
recorded samples, or external asset-store packs are used. Font software is the
separately licensed exception, credited below.

## Audio

All `.wav` files in `assets/audio/` are original mathematical synthesis from
`assets/audio/generate_audio.py`, created for this project. There are no embedded
recordings, model weights, third-party sound libraries, or network dependencies.
The script is the editable source; rerunning it reproduces the PCM files.

| Files | Event and duration | Source |
| --- | --- | --- |
| `click_1.wav` through `click_3.wav` | UI/seat accent, 115 ms | Filtered impulse and wood modes |
| `extract_1.wav` through `extract_3.wav` | Accepted screw tap, 235 ms | Wood modes, low-pass friction, felt accent |
| `wood_1.wav` through `wood_3.wav` | Plate release, 300 ms | Damped inharmonic wood modes |
| `complete_1.wav` through `complete_3.wav` | Box completion, 640 ms | Three ascending felt notes |
| `undo_1.wav` through `undo_3.wav` | Undo, 320 ms | Two descending felt notes |
| `victory.wav` | Level complete, 1.35 s | Original short felt-note phrase |
| `workshop_ambience.wav` | Optional looping ambience, 24 s | Original sparse piano-like miniature |

Masters are uncompressed mono PCM16 at 48,000 Hz. No intentional clipping or
codec artifacts; the loudest generated peak is under 0.53 full scale. Common
event variation is deterministic and narrow. The ambience's endpoints are zero.
Runtime import caches are generated by Godot. No separate claim of recording
authenticity is made: these are synthesized materials.

font installation. Their local filenames are resource conveniences; the internal
typeface names and data remain unchanged.

| `fonts/OpenSans-Regular.ttf` | Open Sans, Google Corporation, packaged by Debian as `fonts-open-sans` | Apache 2.0; `LICENSE-Open-Sans.txt` and `NOTICE-Open-Sans.txt` |

Only the one listed Latin Modern face is included from the complete upstream
family. The upstream manifest is retained as provenance, not an assertion that
every font it lists is distributed here. OpenAI Sans and other proprietary local
fonts are not bundled.

## Visuals

The visual specialist created the following deterministic procedural vectors
for this project. No external image assets are required. Vectors render at
runtime at the actual board scale; the level polygons are authoritative.

| Source | Original artwork |
| --- | --- |
| `scripts/ui/craft_draw.gd` | Six beveled enamel screw identities, their redundant symbols, UI icons, and twelve craft motifs |
| `scripts/ui/board_view.gd` | Parameterized wooden plates, grain, sockets and holes, board backing, shadows, and cosmetic transitions |
| `assets/art/icon.svg`, `icon_192.png`, `icon_512.png` | Original 512-unit vector app icon and Inkscape PNG exports; wooden geometry and enamel screws |
| `assets/art/adaptive_foreground.svg`, `adaptive_foreground.png` | Original transparent crossed planks and screws, 432 × 432, for Android adaptive icon foreground |
| `assets/art/adaptive_background.svg`, `adaptive_background.png` | Original sage adaptive icon background, 432 × 432 |
| `assets/art/README.md` | Art catalog IDs, dimensions, pivots, and rendering notes |

Geometry is shared with the level definitions so the drawings can accurately
communicate logical blocking. The data validation and physical-device visual
review are separate from this provenance record.
