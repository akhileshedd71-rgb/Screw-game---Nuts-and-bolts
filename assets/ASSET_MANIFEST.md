# Screwcraft asset provenance

Game visuals and sounds are built for this project. The attached diagrams are
design references, not a texture sheet copied into the game. No competitor art,
recorded samples, or external asset-store packs are used. Font software is the
separately licensed exception, credited below.

## Audio

All `.wav` files in `assets/audio/` are original mathematical synthesis from
`assets/audio/generate_audio.py`, created for this project. There are no embedded
recordings, model weights, third-party sound libraries, or network dependencies.
The script is the editable source; rerunning it reproduces the PCM files.

| Files | Event and duration | Source |
| --- | --- | --- |
| `click_1.wav` through `click_3.wav` | UI/seat accent, 140 ms | Elastic pitch-gliding pop and marimba glint |
| `extract_1.wav` through `extract_3.wav` | Accepted screw tap, 320 ms | Four toy ratchet ticks, friction, rising pop and bell |
| `wood_1.wav` through `wood_3.wav` | Plate release, 380 ms | Wooden bounce, two damped impacts and rounded pop |
| `complete_1.wav` through `complete_3.wav` | Box completion, 760 ms | Upward four-note C-major bell sparkle |
| `undo_1.wav` through `undo_3.wav` | Undo, 370 ms | Elastic pop and descending marimba notes |
| `victory.wav` | Level complete, 2.25 s | Original “Pip did it!” toy-bell fanfare and bass cadence |
| `workshop_ambience.wav` | Optional looping music, 19.2 s | Original 8-bar, 100 BPM marimba miniature, bells and quiet brushed pulse |

Masters are uncompressed mono PCM16 at 48,000 Hz. No intentional clipping or
codec artifacts; the loudest generated peak is under 0.45 full scale. Common
event variation is deterministic and narrow. The ambience's endpoints are zero.
Runtime import caches are generated by Godot. No separate claim of recording
authenticity is made: these are synthesized materials.

## Visuals

The visual specialist created the following deterministic procedural vectors
for this project. Vectors render at runtime at the actual board scale; the level
polygons are authoritative. New Toybox Workshop illustrations and their separate
generation provenance live in `assets/illustrations/`; these provide original
themed scenery and Pip's character artwork without copying competitor art.

| Source | Original artwork |
| --- | --- |
| `scripts/ui/craft_draw.gd` | Six bright dimensional screw identities, their redundant symbols, original UI icons, and twelve craft motifs |
| `scripts/ui/board_view.gd` | Illustrated toy plates, enamel finishes, sockets and holes, calm board backing, shadows, and cosmetic transitions |
| `assets/illustrations/pip.png`, `pip_victory.png` | Original golden fox toy maker, standing and celebrating with a screw-star trophy; 1254 × 1254 transparent RGBA paintings. Generation provenance: `assets/illustrations/README.md`. |
| `assets/illustrations/toy_world.png` | Original toy village scenery, 1024 × 1536 RGB painting. Same illustration provenance. |
| `assets/art/icon_toybox.png` | Original new app icon: close-up Pip holding pink and aqua screws on purple, 1254 × 1254 RGB. Same illustration provenance. |
| `assets/art/adaptive_toybox_background.svg` | Original purple background used with Pip for the Android adaptive launcher icon. |
| `assets/art/icon.svg`, `icon_192.png`, `icon_512.png` | Retained legacy 512-unit vector app icon and Inkscape PNG exports; wooden geometry and enamel screws |
| `assets/art/adaptive_foreground.svg`, `adaptive_foreground.png` | Retained legacy transparent crossed planks and screws, 432 × 432 |
| `assets/art/adaptive_background.svg`, `adaptive_background.png` | Retained legacy adaptive icon background, 432 × 432 |
| `assets/art/README.md` | Art catalog IDs, dimensions, pivots, and rendering notes |

Geometry is shared with the level definitions so the drawings can accurately
communicate logical blocking. The data validation and physical-device visual
review are separate from this provenance record.
