# Remaining release work

- No physical-device session has been performed. Measure Android frame pacing, startup time, battery/thermals, audio, haptics, safe areas, and suspension on representative phones/tablets.
- The 1,000 deterministic campaign designs have verified routes and valid geometry, but no human pacing/enjoyment study. Some later puzzles share a construction family. Measured witness buffer peaks are not minimum-difficulty proofs.
- Some first-30 brief layer targets are implemented with fewer layers while preserving the exact color inventories; see the authoring report.
- Runtime hints have a bounded search budget and can honestly return unavailable. Undo and Blueprint remain usable.
- Text is authored in English. Full localization, larger-text accessibility layouts, and screen-reader navigation require a separate pass. Color identification does not rely on color alone.
- Android exports use a debug certificate. Store distribution requires the owner's identity, release signing, device QA, and store metadata. No service SDK or monetization system is active.

These limitations do not prevent local development or playing the verified campaign. They prevent calling the build a completed store release or claiming human-tested enjoyment.
